ESTA CARPETA ES EL NUEVO REPOSITORIO PUBLICO "mi-cartera-pwa".
No contiene tus posiciones, tus claves ni el cálculo bursátil.

Para GitHub Pages:
1) Crea repositorio PUBLICO "mi-cartera-pwa".
2) Sube el CONTENIDO de esta carpeta a la raíz del repositorio (no la carpeta).
3) Settings -> Pages -> Deploy from a branch -> main -> /(root) -> Save.
4) Espera a la dirección que GitHub muestre en Pages.
5) Al principio verás una pantalla bloqueada sin cifras reales.

Para conectarla y hacerla dinámica hay que seguir las instrucciones de
INSTRUCCIONES_COMPLETAS.md en el paquete principal.

IMPORTANTE: NO SUBAS EL ARCHIVO holdings.json NI LOS TOKENS AQUÍ.
Las cifras se publicarán posteriormente cifradas en snapshot.enc.json.
Esa carpeta pública puede ser vista y descargada por cualquiera.
La protección de los valores depende de una frase secreta fuerte.
